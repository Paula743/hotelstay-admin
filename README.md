# 🏨 HotelStay Admin - Sistema de Gestión de Reservaciones

HotelStay Admin es una aplicación web responsiva diseñada para optimizar el control de habitaciones, el registro de huéspedes y la administración de reservaciones de hotel en tiempo real. 

## 🚀 Características Principales

El sistema implementa tres módulos completos de tipo CRUD y las siguientes funcionalidades obligatorias:

* **Autenticación de Usuarios:** Registro, inicio y cierre de sesión seguro mediante Firebase Authentication, incluyendo protección de vistas privadas (Dashboard).
* **Gestión de Habitaciones (CRUD):** Registro, edición, baja e inventario de habitaciones (número, piso, tipo, precio por noche y estado).
* **Gestión de Huéspedes (CRUD):** Control detallado de clientes, datos de contacto e identificación.
* **Gestión de Reservaciones (CRUD):** Lógica de negocio para calcular costos por noches y validación automática de disponibilidad de habitaciones.
* **Dashboard Administrativo:** Panel privado con métricas clave (habitaciones disponibles/ocupadas, reservaciones activas e ingresos estimados).
* **Interfaz de Usuario (UI/UX):** Diseño moderno y 100% responsivo basado en Bootstrap 5, tipografía Poppins y componentes dinámicos como galerías multimedia.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript Puro y Bootstrap 5.
* **Backend & Cloud:** Firebase SDK (Authentication & Firestore Database).
* **Metodología de Trabajo:** GitFlow Mínimo (Ramas: `main`, `develop`, `feature/*`).
* **Convención de Commits:** Conventional Commits (`feat`, `fix`, `docs`, `style`).
